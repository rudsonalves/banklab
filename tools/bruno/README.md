# Bruno

Use this directory for Bruno collections used to exercise the BankLab API.

Recommended local variables:

- `base_url`: API base URL, usually `http://localhost:8080`
- `app_token`: value from `APP_TOKEN` in `api/.env`
- `access_token`: JWT returned by login or refresh
- `refresh_token`: opaque refresh token returned by login or refresh

Bruno keeps requests as files, which makes the API collection easier to version
without requiring a paid workspace.
